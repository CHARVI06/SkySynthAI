# Literature Review

## Objective

Review five research papers relevant to temporal enhancement of satellite imagery, optical flow, and deep frame interpolation.

## Required information for each paper

For every paper, record:

1. Citation
2. Problem addressed
3. Dataset
4. Input/output
5. Model/method
6. Evaluation metrics
7. Main findings
8. Limitations
9. Relevance to SkySynthAI

## Research Position

The current project is an implementation and evaluation project, not a claim of a novel interpolation algorithm.

The literature review will be used to:
- justify the problem,
- understand established methods,
- select appropriate datasets,
- identify limitations,
- and define the minor project's practical scope.
