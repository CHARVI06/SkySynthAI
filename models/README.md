# Models Directory

This directory is reserved for local model checkpoints and configuration.

## Git policy

Large model weights/checkpoints should not be committed to the repository.

The `.gitignore` file excludes common checkpoint formats.

Once the exact RAFT and RIFE implementations are finalized, this file should document:
- Official source/repository
- Model version/checkpoint
- Download instructions
- Expected input format
- Expected output format
- License
